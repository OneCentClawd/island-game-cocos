# 小岛物语 - Cocos Creator 版本

🏝️ 一个轻松的岛屿经营小游戏

## 技术栈
- **引擎**: Cocos Creator 3.8
- **语言**: TypeScript
- **平台**: 微信小游戏 / H5

## 项目结构
```
assets/
├── scenes/          # 场景文件
├── scripts/         # TypeScript 脚本
│   ├── managers/    # 管理器（游戏状态、存档等）
│   ├── ui/          # UI 组件
│   └── gameplay/    # 游戏逻辑（建筑、角色等）
├── prefabs/         # 预制体
├── textures/        # 图片资源
├── audio/           # 音频资源
└── data/            # 配置数据
```

## 开发指南

### 1. 安装 Cocos Dashboard
下载: https://www.cocos.com/creator-download

### 2. 打开项目
1. 打开 Cocos Dashboard
2. 点击「导入」
3. 选择此项目文件夹
4. 用 Cocos Creator 3.8.x 打开

### 3. 运行
- 点击编辑器顶部的「播放」按钮预览
- 菜单「项目」→「构建发布」导出微信小游戏

## 游戏功能
- 🏠 建造各类建筑
- 💰 资源管理（金币、木材、食物）
- 👥 人口发展
- 📦 离线收益
- 💾 自动存档
